## How to Run Locally

No installation needed — it's a static website.

### Clone the repository
```bash
git clone https://github.com/Bozhinovska/my_portfolio.git
```

### Open in browser
```bash
cd my_portfolio
open index.html
```

Or simply open `index.html` directly in your browser.
